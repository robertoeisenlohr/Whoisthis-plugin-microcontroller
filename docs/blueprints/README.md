# Blueprints: a WhoIsThis camera built on the XIAO ESP32-S3 Sense

This folder holds the physical designs for the microcontroller device. `measurements.md` is the
dimension sheet everything is drawn from; `candidates.md` lists the form factors proposed for the
first build. Once one is chosen it gets its own folder here with dimensioned drawings, an OpenSCAD
model, a bill of materials and the wiring diagram.

| File | What |
|------|------|
| [`measurements.md`](measurements.md) | Exact sizes of the board, camera, battery, cables and the optional parts, with sources and what still has to be measured on the bench. |
| [`candidates.md`](candidates.md) | Six form factors with envelope sizes, part placement, accessory changes, battery life and the trade-offs of each. |
